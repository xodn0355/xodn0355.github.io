개인정보처리방침 / Privacy Policy

시행일 / Effective: 2026-10-15

1. 앱의 목적 / Purpose

ASTRA Shorts Upload는 운영자 본인이 소유·관리하는 YouTube 채널에 운영자가 직접 만든 영상을 업로드하고 예약 공개를 설정하는 개인용 도구입니다. 운영자 외의 사용자 계정에는 접근하지 않습니다.

This app is used only by its operator to upload the operator's own videos to YouTube channels the operator owns, and to schedule their publication. It does not access other people's accounts.

2. 사용하는 정보 / Data accessed

YouTube Data API를 통해 다음 작업에 필요한 범위만 사용합니다: 영상 업로드, 제목·설명·현지화·예약 시각 설정, 자막과 썸네일 등록, 운영자 영상에 댓글 작성, 업로드 상태 확인을 위한 채널·영상 정보 조회.

Through the YouTube Data API the app only uploads videos, sets titles, descriptions, localizations and publish times, adds captions and thumbnails, posts comments on the operator's own videos, and reads channel and video status to confirm uploads.

3. 저장과 공유 / Storage and sharing

OAuth 토큰은 운영자의 PC에만 저장되며 외부 서버로 보내거나 제3자와 공유하지 않습니다. 업로드 기록(영상 ID, 예약 시각 등)은 운영자의 PC에만 보관합니다. 광고·판매·분석 목적으로 데이터를 사용하지 않습니다.

OAuth tokens are stored only on the operator's computer and are never sent to other servers or shared with third parties. Upload records stay on the operator's computer. No data is used for advertising, sale or analytics.

4. 권한 해제 / Revoking access

Google 계정의 보안 설정(https://myaccount.google.com/permissions)에서 언제든 이 앱의 접근 권한을 해제할 수 있습니다. 해제하면 PC에 저장된 토큰도 더 이상 쓸 수 없습니다.

Access can be revoked at any time at https://myaccount.google.com/permissions. Revoked tokens stop working immediately.

5. Google API 정책 / Google API policy

이 앱이 Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. YouTube API 서비스를 사용하므로 YouTube 서비스 약관(https://www.youtube.com/t/terms)과 Google 개인정보처리방침(https://policies.google.com/privacy)이 함께 적용됩니다.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This app uses YouTube API Services; the YouTube Terms of Service and the Google Privacy Policy also apply.
